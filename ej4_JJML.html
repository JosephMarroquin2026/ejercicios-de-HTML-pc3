Lenguajes de Programación

Los lenguajes de programación permiten crear aplicaciones, páginas web, videojuegos y diferentes tipos de sistemas informáticos.

Java

Java es un lenguaje de programación de propósito general y una plataforma informática orientada a objetos creada en 1995. Funciona bajo el principio de "escribir una vez, ejecutar en cualquier lugar", lo que significa que el código compilado puede correr en cualquier dispositivo que tenga instalada una Máquina Virtual de Java (JVM).

Python

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general que se ha convertido en uno de los más populares del mundo debido a su sintaxis clara y legible. Diseñado originalmente por Guido van Rossum en 1991, destaca por ser multiparadigma, de tipado dinámico y multiplataforma.
